# SmartCash - Dashboard financeiro pessoal desenvolvido com HTML5, CSS3 e JavaScript Vanilla.

## Funcionalidades

- Cadastro de receitas e despesas
- Cálculo automático de entradas, saídas e saldo
- Exclusão individual de transações
- Persistência com LocalStorage
- Layout responsivo
- Tema claro e escuro

## Executar localmente usando Python

```bash
python3 -m http.server 4173
```

Acesse `http://127.0.0.1:4173`.
