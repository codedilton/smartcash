# SmartCash

Dashboard financeiro pessoal desenvolvido com HTML5, CSS3 e JavaScript Vanilla.

## Funcionalidades

- Cadastro de receitas e despesas
- Cálculo automático de entradas, saídas e saldo
- Exclusão individual de transações
- Persistência com LocalStorage
- Layout responsivo
- Tema claro e escuro

## Executar localmente

```bash
python3 -m http.server 4173
```

Acesse `http://127.0.0.1:4173`.

## Publicar no GitHub Pages

1. Faça o push da branch `main`.
2. Abra **Settings > Pages** no repositório.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha `main` e a pasta `/ (root)`.
5. Salve e aguarde a publicação.
